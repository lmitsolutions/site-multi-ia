# Multi-IA — site institucional

Site da **Multi-IA** ("gerente de IAs" em PT-BR, mobile-first, preço em reais) — projeto da **LM IT Solutions** (CNPJ 46.246.833/0001-38).

## Publicar

Este é um site estático de página única (`index.html`). Para colocar no ar gratuitamente:

- **GitHub Pages:** Settings → Pages → Deploy from a branch → `main` / root.
- **Cloudflare Pages:** conectar este repositório; build vazio, diretório de saída `/`.

## Estrutura

- `index.html` — página única (HTML + CSS + JS inline).
